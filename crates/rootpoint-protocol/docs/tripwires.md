# Tripwires of rootpoint-protocol

Evidence that would flip a recorded decision of rootpoint-protocol: one level-two heading per
tripwire, each naming its decision. What is outstanding is in `register@rootpoint-protocol@issue`.

## Guarding `design@rootpoint-protocol@gesture-undo`: a command of another client joins the GUI's undo group `##client-joins-gui-group`

**Fires when:** with the control socket of `spec@first-prototype@live-control` built, a command from the socket
arrives while a group the GUI opened with `begin` is open, and joins it, so one `undo` reverts the
agent's edit with the GUI's gesture.
**Response:** reopen `design@rootpoint-protocol@gesture-undo`, for example with one group per
client.
**Re-entry:** the design audit of `spec@first-prototype@live-control`.
