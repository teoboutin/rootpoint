# Rejected designs of rootpoint

The designs not kept for rootpoint, and why: one level-three heading per design, each cited by the
design head whose argument covers it, in `register@rootpoint@design`.

### Refusing a saved presentation of every earlier version of the save format `##refuse-earlier-versions`

`live`. A file of the version before is the owner's presentation: refused after an update, it
loses the talk prepared in it, against `goal@rootpoint@real-presentations`, on the owner's word that
compatibility holds for saved presentations. Its saving, no step and no frozen file per breaking
change, does not weigh against that loss.
