# Rejected designs of rootpoint

The designs not kept for rootpoint, and why: one level-three heading per design, each cited by the
design head whose argument covers it, in `register@rootpoint@design`.

### A migration of each earlier version of the save format `##format-migration`

`live`. A loader of each earlier version costs code and a test per version, and no presentation
exists to read: the owner gives no real presentation with the project while it is in initial
development, and keeps no compatibility until the owner rules that real use has begun. From that
ruling, a change of format is the case this design answers.
