# Nothing yet fulfils the goals of rootpoint

## Summary

The project holds no code beyond the maintenance tool. No goal of rootpoint is met, and no plan
document schedules the work that would meet one.

## Details

### What

The editor, its model of a presentation, its save file, its presenter mode and its text command
protocol do not exist. Their design is not discussed yet.

### Why it matters

Every goal of rootpoint is unmet while this stands: `goal@rootpoint@real-presentations`,
`goal@rootpoint@no-language-no-build`, `goal@rootpoint@free-slide-division`,
`goal@rootpoint@minimal-content-set`, `goal@rootpoint@presenter-mode`,
`goal@rootpoint@readable-save-file`, `goal@rootpoint@headless-core`,
`goal@rootpoint@text-command-protocol` and `goal@rootpoint@runs-in-browser`.

### What would close it

A design discussion under `skill@knowledge-architect-design` for the first prototype, which edits
images and plain text, saves to a text file and shows presenter mode, and the spec or milestone it
hands to `skill@knowledge-architect-planning`. The plan document then schedules the work, and this
entry is deleted in the commit that adds it.
