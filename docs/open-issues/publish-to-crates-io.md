# No crate is published to crates.io

## Summary

`goal@rootpoint@real-presentations` admits that the tool may be published later. Every crate is
`publish = false`, and none has a page for crates.io.

## Details

### What

Publishing gives each published crate a `CRATES-IO.md` page, as
`skill@knowledge-architect-setup@rust-project` proposes, a version scheme and the metadata
crates.io asks for.

### Why it matters

None while the tool serves the owner alone: no one else can install it from crates.io. The owner
named publishing to crates.io as probable later, if the tool works out well.

### What would close it

The owner's word to publish, then the pages, the metadata and a first release; or the owner's
word that the tool stays unpublished.
